# 图片与论文图复现

参考图片复现默认采用用户选定的 Previous local tracing，按 [local-tracing.md](local-tracing.md) 分组件沿原图描摹，文字和规则几何另行重建。模糊输入或“更精致”不自动切换结构精绘、图库替换或生成重画；明确要求探索其他路线时才读 [precision-redraw.md](precision-redraw.md)。使用现有参考与要求推断合理默认值，仅在缺失信息确实阻塞时提问。

论文出处明确时检查公开 PDF/SVG/作者源文件，优先保留原始路径，嵌入位图仍按位图处理。PDF 的隐藏备用层、裁剪及透明叠加需与实际显示对照。局部工具及选择依据见 [detail-matching.md](detail-matching.md)。

区分文字、框/箭头、规则几何、不规则插画与实验图像，在统一画布记录位置。文字见 [text-manifest.md](text-manifest.md)。规则几何直接写 SVG，复杂图标默认裁剪源图并局部描摹；同一原图的确切原始路径可核对后复用。跨库找同类图标替换仅按明确要求执行；整页描摹不代表识别了全部对象。

用户认可的文字与框保持稳定 ID，仅修改选定图标。`check_preserved.py` 比较指定组件外的文字、几何、样式与顺序；`--all-icon-groups` 仅排除旧格式 data-icon-key 图标组。不要排除全部组件后宣称文字与框均受保护。

位图含字时，先记录文字，用可用的 imagegen 工作流制作独立去字副本并核对关键图形。恢复文字使用原始坐标。仅当副本确实去字后传 `--text-already-removed`。缺少编辑工具时按几何重建，或明确字形仍是不可打字的路径；不自动索要外部 API Key。描摹不包含隐藏水印检测或去除。

优先核对轮廓、数量、方向、结构关系和遮挡，再看配色线宽。局部对照使用同一裁剪范围与缩放。默认以 `detail` 为起点；`balanced/clean` 不因路径更少就自动优先。形态不对时复查裁剪、背景处理和描摹参数，不自行改成另一种组件。查看实际 PPT，只调整尚存问题，验收通过后完成交付。
