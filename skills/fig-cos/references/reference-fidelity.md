# 参考图约束下的保形修复

此文保留替代修复方法的研究与候选检查办法。用户已选 [Previous local tracing](local-tracing.md) 为默认，不因“更清晰”自动采用本研究路线。仅在明确要求探索替代修复方法时读取；不是已集成的超分或自动语义修复模型。

## 先建立形态证据

在未处理的原图上定位外轮廓、关键拐点、部件接触位置、细线端点与分叉、前后遮挡。记录哪些是直接可见，哪些模糊但有范围约束；不要由类别名称重新想象物体。原图与用户较认可的旧版都保留，作为候选比较基线。

垃圾桶：核对桶盖厚度和透视、桶沿是否贴合桶身、各面宽度、凹槽位置、可见轮子与接触关系。蛋白：核对原图中的连续螺旋带、轴线方向、可见连接环和交叠顺序。相近的分子类别或另一种折叠不是复现依据；没有结构 ID 时可以精绘二维可见表达，不必编造 PDB 身份。

## 按图形选择方法

- 可辨的直线、圆弧、平滑轮廓：沿参考定位关键点，分段拟合 Bézier；保留确切拐角和接触点。拟合误差根据原始像素的不确定度设定，不能为“更顺”而挪动明显结构。
- 螺旋、丝带、连接环：先沿参考建立轴线/边界和遮挡分段，再绘制连续带的前后面与厚度。保持参考的布局与可见绕转节奏，不以独立圆片排列冒充螺旋。未知的背面连接不擅自接通。
- 重复细胞/颗粒：从原图恢复每个可辨实例的位置、大小与边界；模糊处保留不确定性，不能自动变成等间距模板。
- 源位图中的细线与半透明层：将边缘/细线和大面积色块分开处理。去背景、量化、去斑和路径简化可能吞线；预处理前后都比较连接和负空间。不要把被预处理误删的线当成源图没有的线。
- AI/图库：可帮助寻找同一素材、提出局部候选或补充非结构性的明暗。候选也必须通过原图约束。边缘控制和文字提示不是拓扑保证；模型可用、实际推理、结构验收是三种状态。

## 候选比较

1. 用原图的同一裁剪框、位置、纵横比叠加检查，不靠任意缩放、旋转掩盖差异。
2. 看轮廓、关键点、部件接触、连接/分叉、遮挡、镂空和细线是否保留，再看曲线连续性与光影。
3. 将高分辨率渲染经过合理模糊与降采样，与原始像素比较。颜色误差、边缘距离和区域重合可发现明显漂移，不能代替结构检查；小面积关键连接不能被整幅均值淹没。
4. 同时查看目标实际尺寸与放大局部。若结构退步或只有路径数减少，候选保留为实验，不替换原版。全图文字、框与已认可组件继续使用局部保护检查。

## 研究方法及真实集成状态

- [Potrace 原始论文](https://potrace.sourceforge.net/potrace.pdf)：轮廓、角点和平滑曲线的经典路线；主要针对二值图，不等于彩色科研插图语义修复。当前没有新增 Potrace 后端。
- [DiffVG](https://people.csail.mit.edu/tzumao/diffvg/)：可微矢量光栅化，可用重渲染误差优化路径。拓扑/关键点仍需任务约束；当前未集成或运行。
- [LIVE](https://openaccess.thecvf.com/content/CVPR2022/html/Ma_Towards_Layer-Wise_Image_Vectorization_CVPR_2022_paper.html)：逐层增加和优化路径，关注紧凑分层及图像拓扑。论文效果不保证保留科研图中的所有连接；当前未集成或运行。
- [SwinIR 官方实现](https://github.com/JingyunLiang/SwinIR)：超分、去噪、JPEG 伪影恢复，可作为候选预处理；不同任务/权重需分别评估，不能假设细线或科学结构一定保真。当前未集成或运行。
- [ControlNet](https://arxiv.org/abs/2302.05543)：边缘、分割等空间控制可辅助局部生成；不是像素或拓扑锁定。当前没有接入专用 ControlNet 后端。
- [SUPIR](https://arxiv.org/abs/2401.13627)：生成式照片修复研究，论文也专门处理保真度问题。科研结构复现不宜默认采用；当前未集成或运行。权重和代码使用条件须按对应仓库核实。

对本技能最值得探索的是“原图定位/分层 → 有约束曲线拟合 → 重渲染比较”的组合，这是基于上述方法作出的工程判断，不是声称某篇论文已经实现了本技能需求。用低成本局部案例先验证，保留失败对照，再决定是否引入模型或新依赖。
