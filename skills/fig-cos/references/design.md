# 从头设计与绘制

从科学信息与关系开始：图的核心信息、对象和箭头的含义、已有证据支持什么。区分实验观测与机制假设，不为填满版式增加未知机制或虚构数值。

安排阅读顺序、主次层级、面板和标签，再处理留白对齐。未指定尺寸时按用途选择合理画布并说明；普通样式决策无需反复确认。按内容选择流程、分层机制、比较面板或中心展开，不把示例版式固定化。

用真实文本与几何编写 SVG，或通过 `compose.py` 的 JSON 装配。图库按具体形态选择，仅在几何和图库不能满足局部插画时引入 [AI 素材](ai-assets.md)。

需要模糊参考下更清晰、更有层次的组件时，读取 [结构精绘](precision-redraw.md)，以可辨部件和关系约束新绘制。原生渐变和解析曲线可提高视觉精度，无须用很多碎路径模拟材质；未知科学身份仍要保留不确定性。

可运行模板 `assets/templates/editable-components.json` 展示两个程序组件：

- `dna`：圈数、振幅、链宽与颜色、横杆和交替前后关系。是示意双链，不是特定序列或原子结构。
- `cell-cluster`：细胞位置/半径、核膜配色、突出细胞索引。位置由用户或设计指定，不作为测量数据。

在场景中用 `kind=parametric`，或调用 `parametric.draw_component(kind, parameters, target)`。其他形态可扩展本次任务的绘图代码，或以独立 SVG 接入；不宣称这些参数覆盖全部生物学。

图形用独立组件，文字、箭头、图标和框各自可编辑；面板需要整体移动时增加 group。PPT 保留嵌套组合，单个原生对象无需额外空组合。

检查标签含义、箭头是否区分因果/流程/关联、颜色的语义及缩小后的可读性。复杂程度服务表达，避免堆图标代替关系。查看 SVG 与实际 PPT，按任务附场景、代码或组件。
