# AI 生图 → 矢量组件 → 可编辑图

生图与转换是独立步骤。技能不内置生成模型或密钥配置；使用宿主可用的 imagegen skill/内置图片工具生成与编辑，再处理本地图片。内置工具不可用时不自动切换外部 API；可继续矢量绘制或处理用户已有图片，明确未执行的生成步骤。

先确定素材的结构、部件、朝向与放置区域，写入生成约束并逐项检查。外观合理不证明科学内容正确。优先生成无字的独立局部素材，文字/箭头/框由 SVG/PPT 恢复。

适合转矢量的提示可按需包含平面插画、清晰边缘、有限色阶、适量细节、无文字、无复杂纹理，不能覆盖用户明确风格。需要透明背景时由生图工具请求真实 alpha，遵循 imagegen 的输入引用与保存流程。保留最终提示、图片与生成方式。

用户要求从模糊参考精绘时，生成约束应明确哪些轮廓、部件、数量和空间关系是确定的，哪些只允许作示意。让生成工具重绘边缘与层次，不能声称模型恢复了隐藏分子身份；输出后按 [precision-redraw.md](precision-redraw.md) 校验。若追求大量纹理的生成结果不适合编辑，应选择直接矢量精绘或明确约定混合输出。

参考修复还需保留具体形象与可见结构，不能只满足类别正确。边缘条件/提示词不是结构硬锁；候选改变螺旋表现、部件接触或原有外形时不作为精绘升级。局部遮罩与控制信号是否可用须按实际工具确认，不虚构当前宿主能控制的参数。比较方法见 [reference-fidelity.md](reference-fidelity.md)。

用户要求整图先生成时先检查布局结构，再分区处理；整图颜色描摹不是语义分割。允许混用 AI 局部、图库、程序矢量和真实文字。

```powershell
python SKILL/scripts/trace_asset.py --input-image inspected-text-free.png --text-free --source-kind ai-generated --preset detail --output-dir new-component
```

输出 `component.svg` 和 `provenance.json`，保留源文件、哈希与近似说明。描摹只恢复颜色轮廓，不恢复文字、语义、原始渐变或透明图层；对照源图检查细线、镂空及叠加。不准的关键区域直接重建。

然后以 `kind=svg` 加入场景，或直接用 `kind=trace`：file 指向已检查的无字图片，`text_free=true`，`source_kind=ai-generated`；标签单独用 `kind=text`。接口见 [components.md](components.md)。

全矢量导出要求真实路径和文字。用户明确要求保留照片/纹理时，可用演示文稿工具制作混合输出并标明图片对象，当前全矢量导出器不静默降级。

生成成功、图片已检查、组件已检查、PPT 已渲染和最终验收是不同状态，只有实际完成后才记录。场景脚本接收已生成图片，不代替宿主调用生成模型；转换测试通过不能声称 AI 生图已运行。
