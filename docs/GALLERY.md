# Gallery, provenance and image rights

These are real historical outputs from the figure workflow, not newly AI-generated marketing images. Their previews were inspected before inclusion. File hashes below identify the exact unchanged preview images.

## Biomni figure reconstruction

![Historical actual PowerPoint render](images/biomni-reconstruction.png)

Adapted from **Huang et al., Biomni: A General-Purpose Biomedical AI Agent**, bioRxiv 2025, Figure 1. DOI: [10.1101/2025.05.30.656746](https://doi.org/10.1101/2025.05.30.656746). The preprint is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); source and license can also be checked on [bioRxiv](https://www.biorxiv.org/content/10.1101/2025.05.30.656746v1). This modified figure is a technical reconstruction demonstration, not an original scientific result or an endorsement by the authors.

Changes: rebuilt live text, frames and arrows; recovered/traced scientific pictograms; retained approximate visible appearance; some generic robot/database/gear/plot icons replaced by Lucide vectors; paper thumbnails rendered as schematics. Original raster/alpha layers and semantic source objects were not recovered. This historical case is a hybrid; future reference reconstruction defaults to local source tracing rather than automatic icon substitution. [Recorded historical metrics](gallery-metrics.json).

## Source-derived detail comparison

![Original, earlier library substitution, source-derived reconstruction](images/source-details.png)

The left/right columns derive from the same Biomni figure and are CC BY 4.0 adaptations. The middle column shows an earlier imperfect library substitution, not the recommended default: Lucide network icon (ISC / applicable Feather MIT), antibody illustration by Servier (CC BY 3.0, via Bioicons), and ribosome by jaiganesh (CC0, via Bioicons). Individual credits and links are in [asset-attributions.json](asset-attributions.json). The comparison was assembled to show why category similarity is insufficient.

## Procedural editable components

![Historical actual PowerPoint render](images/editable-components.png)

Original fig-cos scene with a schematic DNA helix and cell cluster. Python/scene source: MIT. No atomistic identity, measured cell morphology or empirical data is represented. [Reproducible assets](../examples/procedural/scene.json).

## Scope of public examples

Private input screenshots, conversation archives, local paths, experimental work folders and other publisher-restricted reference figures are not part of this distribution. The generic bin/protein redraw that failed fidelity review is not promoted as a reconstruction showcase.
