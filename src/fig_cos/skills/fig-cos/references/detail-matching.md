# 细节匹配与局部恢复

参考图片复现默认按 [局部描摹基线](local-tracing.md) 执行；本文件中的跨库替换/另行重画方案仅在用户明确要求时采用。同一原图的确切原始路径可核对后复用。

## 选择依据

先记录参考图中的科学对象与表达形式，例如“绿色 β 桶状蛋白丝带”“多种微生物的集合”“带突出细胞的半透明细胞簇”。没有证据时不推断蛋白名称或 PDB 编号。抗体与蛋白丝带、培养皿与细胞簇、组织切片与上皮细胞等不能因主题相近而互换。

候选比较依据为具体类型、轮廓、朝向、部件数量及空间关系、表现形式（丝带/表面/剖面）、细节密度，之后再统一线宽、颜色和阴影。用 `candidate_board.py` 可跨库查看真实预览；搜索词逐步细化，不将第一条结果直接装配。没有合适素材时进入局部恢复或重绘。

## 可用路径

1. 原始 PDF/SVG/作者源文件：优先复用原始路径及可获得的独立素材，核对许可和原图可见状态。
2. 跨库匹配：Bioicons、Reactome、SciDraw 可直接搜索下载；NIH BioArt 支持条目和预览解析，实际格式及许可逐项确认。
3. 确切分子结构：用户提供或能由文献确认 PDB/mmCIF ID 时，可用结构渲染工具选择视角、链、cartoon 或 surface，再按目标软件导出。不凭相似轮廓编造结构身份；未运行的结构渲染器不称为已集成。
4. 规则细节：DNA 用交替前后遮挡的双曲线、碱基横杆绘制；细胞簇按数量、大小、遮挡和异常细胞位置装配；核苷酸和磷酸链按化学关系绘制。代码参数要控制具体形态，不能用通用图标代替结构。
5. 非规则细节：对源图局部逐层描摹，必要时按现有图片工具流程生成局部素材，再转路径。标注轮廓/渐变近似，核对透明叠加及小结构。不要将照片的描摹路径当作可解释的生物学部件。

## PDF 局部素材工具

```powershell
python SKILL/scripts/pdf_region_assets.py --pdf paper.pdf --page 15 --box 182 307 204 336 --output-dir new-component
```

页码从 1 开始，box 为 PDF 点坐标 x0 y0 x1 y1。工具保留区域内完整包含的原生路径，将嵌入图片连同 alpha mask 提取后用 VTracer 局部描摹；输出组件 SVG、参考裁剪图及 provenance.json。只自动保留图标内短标签 P/AI，其余文字仍通过文字清单恢复。

该工具不是通用无损 PDF 转换器：跨越区域边界的对象、复杂裁剪、混合模式和隐藏备用图层需检查。先看 reference-region.png 对照组件，再决定是否采用。`--exclude-xref` 和 `--exclude-vector-seqno` 用于已核实的备用/遮罩图层，不盲目批量排除。

半透明位图叠加可用 `--composite-raster-layer` 先按顺序合成再描摹。此方式近似最终颜色，无法保留原始可调 alpha 图层；工具会去除全画布白底路径，以减少外部遮挡。仍需核查留白、镂空、细边及叠放顺序。

## 局部修改验收

用户认可文字和框时，保存原版本，只替换图标组。核对：组外文字/框的坐标和样式保持；按可见图形边界缩放，避免素材画布留白使图标变小；图标内的白底、隐藏层不覆盖相邻标签；新增短标签保持可编辑。

检查整图和放大局部。SVG 与实际 PowerPoint 预览均需查看；导出路径数量只反映结构，不代表相似度。来源清单区分原始路径、图库替换、源位图描摹和新绘制，保留作者、许可和修改说明。论文中的源素材不自动成为通用可再分发图库素材。
